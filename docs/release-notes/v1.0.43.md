# v1.0.43

## Hạn mức Antigravity hiện lại

- Antigravity 2.34 đổi cách cấp quyền truy cập nội bộ, nên notch mất số hạn mức và thẻ Antigravity. Bản này đọc lại được cả hai.
- Khi Antigravity khởi động lại phần chạy nền, notch tự bắt lại sau vài giây.

## Duyệt lệnh Antigravity ngay trên notch

- Script duyệt lệnh dùng chung với Claude Code và Codex giờ chạy được cả với Antigravity. Cách cài có trong README.
- Lệnh chạy trong sandbox vẫn tự chạy như thường. Chỉ lệnh xin ra khỏi sandbox mới hiện banner Antigravity để bấm Đồng ý hoặc Không.
- Notch tắt hoặc không ai bấm thì Antigravity tự hỏi lại trong app.

# v1.0.43 (English)

## Antigravity limits are back

- Antigravity 2.34 changed how it grants local access, so the notch lost the limit bars and the Antigravity cards. This build reads both again.
- When Antigravity restarts its background server, the notch picks it up again within a few seconds.

## Approve Antigravity commands on the notch

- The approval script shared with Claude Code and Codex now works with Antigravity too. The README shows how to set it up.
- Commands inside the sandbox run as before. Only a command asking to leave the sandbox opens the Antigravity banner, where you press Allow or Deny.
- If the notch is closed or nobody answers, Antigravity asks in its own window.
