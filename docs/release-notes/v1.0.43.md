# v1.0.43

## Ổn định kết nối quota và duyệt Antigravity

- Chọn tiến trình `language_server*.exe` mới nhất theo thời điểm khởi chạy (hỗ trợ cả tên file mở rộng và tránh bám nhầm tiến trình cũ sau khi server khởi động lại).
- Đọc cổng HTTP linh hoạt hơn trong `language_server.log` và ghi log chẩn đoán vào `%APPDATA%\PuwNotch\puw-notch.log` nếu mất kết nối.

# v1.0.43 (English)

## More reliable Antigravity quota and approval discovery

- Picks the newest `language_server*.exe` process by start time (matching versioned exe names and avoiding stale processes after a server restart).
- Parses the HTTP port from `language_server.log` more flexibly and writes a diagnostic line to `%APPDATA%\PuwNotch\puw-notch.log` if lookup fails.
