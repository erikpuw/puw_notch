# v1.0.43

## Duyệt lệnh Antigravity qua Hook chính thức

- `tools/puw-notch-approve.ps1` hỗ trợ thêm định dạng `PreToolUse` của Antigravity (`~/.gemini/config/hooks.json`), nối thẳng vào Named Pipe `puw-notch-approve` như Claude Code và Codex.
- Lệnh trong sandbox tự động cho qua, chỉ lệnh cần `BypassSandbox` mới hiện banner duyệt trên notch; nếu notch tắt hoặc bận thì trả về `ask` để hỏi lại trong Antigravity.

## Ổn định kết nối quota và duyệt Antigravity

- Chọn tiến trình `language_server*.exe` mới nhất theo thời điểm khởi chạy (hỗ trợ cả tên file mở rộng và tránh bám nhầm tiến trình cũ sau khi server khởi động lại).
- Đọc cổng HTTP linh hoạt hơn trong `language_server.log` và ghi log chẩn đoán vào `%APPDATA%\PuwNotch\puw-notch.log` nếu mất kết nối.

# v1.0.43 (English)

## Approve Antigravity commands via official Hooks

- `tools/puw-notch-approve.ps1` now supports Antigravity's `PreToolUse` JSON contract (`~/.gemini/config/hooks.json`), talking directly to the `puw-notch-approve` Named Pipe like Claude Code and Codex.
- Sandboxed commands pass through right away; only `BypassSandbox` commands open the notch banner, falling back to `{"decision":"ask"}` if the notch is closed or busy.

## More reliable Antigravity quota and approval discovery

- Picks the newest `language_server*.exe` process by start time (matching versioned exe names and avoiding stale processes after a server restart).
- Parses the HTTP port from `language_server.log` more flexibly and writes a diagnostic line to `%APPDATA%\PuwNotch\puw-notch.log` if lookup fails.
