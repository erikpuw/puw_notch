# v1.0.42

## Khởi động cùng Windows không chớp cửa sổ hay taskbar

- Scheduled Task chạy thẳng `puw_notch.exe` với bản thường và chạy qua `explorer.exe` với bản ký số `uiAccess`, bỏ hoàn toàn `powershell.exe` trung gian nên đăng nhập không còn chớp khung Terminal hay icon trên taskbar.
- Nếu anh đã bật tự khởi động ở bản cũ, tắt rồi bật lại "Khởi động cùng Windows" ở tray một lần để cập nhật Scheduled Task mới.

## Tự né chuẩn hơn với Microsoft Store và ứng dụng WinUI

- Thêm `ApplicationFrameWindow` và `WinUIDesktopWin32WindowClass` vào danh sách cửa sổ luôn thu mini khi chạm mép trên, nên notch không còn đè lên ô tìm kiếm trên thanh tiêu đề của Microsoft Store.

# v1.0.42 (English)

## No console or taskbar flash at Windows logon

- The scheduled task now launches `puw_notch.exe` directly on standard builds and through `explorer.exe` on signed `uiAccess` builds, removing `powershell.exe` so logging in no longer flashes a Console window or taskbar icon.
- If you enabled autostart on an older build, toggle "Start with Windows" off and back on in the tray once to update the scheduled task.

## Better auto-dodge for Microsoft Store and WinUI apps

- Added `ApplicationFrameWindow` and `WinUIDesktopWin32WindowClass` so the notch shrinks to mini whenever these windows reach the top edge instead of covering the Microsoft Store titlebar search box.
