# v1.0.44

## Trình cài đặt mới (`puw_notch_setup.exe`)

- Thêm trình cài đặt 1 file (~991 KB) viết bằng Rust/Win32, song ngữ Việt/Anh, hỗ trợ cài mới và gỡ cài đặt trong Windows Settings → Apps.
- Cho phép chọn thư mục cài đặt tuỳ ý qua hộp thoại chọn thư mục chuẩn Windows (mặc định `C:\Program Files\PUW Notch`).
- Hiển thị bảng **Quyền & thay đổi trên máy** trước khi cài, có biểu tượng khiên UAC trên nút Cài đặt và chỉ xin quyền quản trị khi bấm.
- Tùy chọn tạo Scheduled Task `PuwNotch` khởi động cùng Windows (chạy thẳng `puw_notch.exe`, không chớp cửa sổ), tạo lối tắt Start Menu/Desktop và tự đóng bản đang chạy trước khi ghi đè.

# v1.0.44 (English)

## New Windows installer (`puw_notch_setup.exe`)

- Added a single-file (~991 KB) Rust/Win32 installer and uninstaller with a VI/EN switch and Windows Settings → Apps registration.
- Pick any installation folder with the native Windows folder dialog (defaults to `C:\Program Files\PUW Notch`).
- Shows a **Permissions & system changes** summary before installing, places the UAC shield on the Install button and only elevates when clicked.
- Optional Windows logon Scheduled Task (`PuwNotch`, direct exe launch with no console flash), Start Menu/Desktop shortcuts, and automatic shutdown of any running `puw_notch.exe` before updating.

**Full Changelog**: https://github.com/erikpuw/puw_notch/compare/v1.0.43...v1.0.44
