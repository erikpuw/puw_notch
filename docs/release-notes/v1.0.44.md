# v1.0.44

## Trình cài đặt mới (`puw_notch_setup.exe`)

- Thêm trình cài đặt 1 file (~998 KB) vẽ bằng Win32 GDI thuần căn giữa màn hình, theo Dark/Light mode của Windows, đổi ngôn ngữ Việt/Anh và đăng ký gỡ cài đặt trong Windows Settings → Apps.
- Chọn thư mục cài đặt tuỳ ý qua hộp thoại chọn thư mục chuẩn Windows (mặc định `C:\Program Files\PUW Notch`).
- Hiện sẵn mục **Quyền & thay đổi trên máy** trước khi cài, chỉ xin quyền quản trị (UAC) khi bấm cài vào thư mục hệ thống hoặc tạo lịch khởi động.
- Tùy chọn tạo Scheduled Task `PuwNotch` khởi động cùng Windows (chạy thẳng `puw_notch.exe`, không chớp cửa sổ) và tạo lối tắt Start Menu/Desktop.
- Lưu ý: nếu PUW Notch đang chạy, nên tắt trước khi cài đặt hoặc cập nhật (chuột phải biểu tượng ở khay hệ thống → **Thoát**).

# v1.0.44 (English)

## New Windows installer (`puw_notch_setup.exe`)

- Added a single-file (~998 KB) pure Win32 GDI installer and uninstaller centered on screen, matching Windows Dark/Light mode with a VI/EN switch and Windows Settings → Apps registration.
- Pick any installation folder with the native Windows folder dialog (defaults to `C:\Program Files\PUW Notch`).
- Lists **Permissions & system changes** before installing and only prompts for UAC elevation when writing to a system folder or creating the startup task.
- Optional Windows logon Scheduled Task (`PuwNotch`, direct exe launch with no console flash) and Start Menu/Desktop shortcuts.
- Note: if PUW Notch is already running, close it before installing or updating (right-click the tray icon → **Quit**).

**Full Changelog**: https://github.com/erikpuw/puw_notch/compare/v1.0.43...v1.0.44
